# Student Data Management System

A menu-driven C project using a Singly Linked List.

## Features
- Add records
- Delete records
- Show records
- Modify records
- Save and load records
- Sort records
- Delete all records
- Reverse the list

## Technologies
- C
- Singly Linked List
- Dynamic Memory Allocation
- File Handling

## Compilation

cc student_record.h student_main.c student_record.c 

## Run

./a.out
